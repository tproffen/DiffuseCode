Structures#

diffuse.read_structure(path, supercell=None)[source]#

Read a structure file into DISCUS.

Parameters:

  • path (str or os.PathLike) – A .cif or .cell file (an asymmetric unit: DISCUS applies the space group) or a .stru file (a whole crystal).

  • supercell (int or tuple of 3 int, optional) – Number of unit cells along a, b and c; an int means the same along all three. Default: 1 x 1 x 1 for .cif/.cell, and a .stru file is read as it is.

Returns:

Crystal – The structure, now held by DISCUS.

Raises:

  • FileNotFoundError – If path does not exist.

  • DiffuseError – If the file type is not supported.

  • MacroError – If DISCUS cannot read the file.

Return type:

Crystal

Examples

>>> import diffuse as dc
>>> cr = dc.read_structure("anatase.cif", supercell=(10, 10, 4))
>>> cr.natoms
4800

view(style='ball', *, scale=1.0, cell='crystal', show=None, colors=None, width=640, height=480, background='white')[source]#

Show the structure in 3D in a Jupyter notebook (py3Dmol).

Rotate with the left mouse button, zoom with the wheel, move with the right button (or Ctrl + left). Uses py3Dmol (3Dmol.js), which is installed with the package.

Parameters:

  • style ({"ball", "spacefill", "stick", "ballstick"}) – Small spheres (default), touching spheres, or bonds; bonds are drawn between atoms closer than the sum of their covalent radii.

  • scale (float) – Size factor for the spheres and sticks, e.g. 3 for a sparse model structure whose atoms are far apart.

  • cell ({"crystal", "unit"} or None) – Draw the edges of the whole crystal (all unit cells), of one unit cell, or nothing.

  • show (str or sequence of str, optional) – Only these atom types (DISCUS names such as "CU"), for example to see how one kind of atom is ordered.

  • colors (dict, optional) – Colours for atom types, e.g. {"CU": "orange", "AU": "gold"}. Other atoms are coloured by element (Jmol colours).

  • width (int) – Size in pixels.

  • height (int) – Size in pixels.

  • background (str) – Background colour.

Returns:

StructureView – Displayed when it is the last expression in a notebook cell (or call .show()). .write_html("file.html") saves a page that shows the structure in any browser. The py3Dmol view is .viewer; other py3Dmol methods (addLabel, setView …) can be called on the StructureView directly, then .show().

Notes

Fine for tens of thousands of atoms with "ball"; bonds ("stick", "ballstick") get slow for large crystals.

diffuse.powder(crystal, *, qmin=0.5, qmax=10.0, dq=0.005, radiation='xray', wavelength=0.2, method='debye', temperature=True, lp_correction='none')[source]#

Calculate the powder pattern of a crystal with DISCUS.

Parameters:

  • crystal (Crystal) – The structure, from read_structure().

  • qmin (float) – Q range and step in Å⁻¹.

  • qmax (float) – Q range and step in Å⁻¹.

  • dq (float) – Q range and step in Å⁻¹.

  • radiation ({"xray", "neutron", "electron"}) – Radiation type; selects the atomic form factors or scattering lengths.

  • wavelength (float) – Wavelength in Å, used for the Lorentz-polarisation factor and for PowderPattern.two_theta().

  • method ({"debye", "complete"}) – "debye": Debye equation, for any structure, including finite particles. "complete": Fourier transform on a reciprocal-space grid, for periodic crystals.

  • temperature (bool) – Apply the atomic displacement parameters.

  • lp_correction ({"none", "bragg", "neutron"}) – Lorentz-polarisation correction.

Returns:

PowderPattern

Raises:

  • ValueError – For an unknown radiation or method, or an invalid Q range.

  • MacroError – If the calculation fails inside DISCUS.

Return type:

PowderPattern

Examples

>>> p = dc.powder(cr, qmin=0.5, qmax=10, dq=0.005, radiation="neutron")
>>> p.plot()

Single-crystal diffraction#

diffuse.fourier(crystal, *, ll, lr, ul=None, npoints=(201, 201), radiation='xray', wavelength=None, temperature=True, subtract_average=0.0)[source]#

Calculate single-crystal intensities on a line or plane with DISCUS.

Parameters:

  • crystal (Crystal) – The structure, from read_structure().

  • ll (sequence of 3 float) – Lower-left and lower-right corner (h, k, l); the abscissa runs from ll to lr.

  • lr (sequence of 3 float) – Lower-left and lower-right corner (h, k, l); the abscissa runs from ll to lr.

  • ul (sequence of 3 float, optional) – Upper-left corner; the ordinate runs from ll to ul. Leave it out for a line.

  • npoints (int or (int, int)) – Number of points along the abscissa and the ordinate (a plain int for a line, or the same along both axes of a plane).

  • radiation ({"xray", "neutron", "electron"}) – Radiation type; selects the atomic form factors or scattering lengths.

  • wavelength (float, optional) – Wavelength in Å. Default: DISCUS’s current setting.

  • temperature (bool) – Apply the atomic displacement parameters.

  • subtract_average (float) – Percentage (0–100) of the average structure’s scattering to subtract. 100 removes the Bragg peaks of the average structure and leaves the diffuse scattering of a disordered crystal.

Returns:

FourierMap

Raises:

  • ValueError – For an unknown radiation, bad corners or point counts.

  • MacroError – If the calculation fails inside DISCUS.

Return type:

FourierMap

Examples

The hk0 plane from -3 to 3 in h and k:

>>> f = dc.fourier(cr, ll=(-3, -3, 0), lr=(3, -3, 0), ul=(-3, 3, 0),
...                npoints=(301, 301))
>>> f.plot(log=True)

Pair distribution function#

diffuse.pdf(crystal, *, rmax=20.0, dr=0.01, radiation='xray', qmax=0.0, qdamp=0.0, qbroad=0.0, thermal=True, corrlin=0.0, corrquad=0.0, particle_diameter=None)[source]#

Calculate the pair distribution function G(r) of a crystal with DISCUS.

Parameters:

  • crystal (Crystal) – The structure, from read_structure().

  • rmax (float) – Largest distance and step in Å.

  • dr (float) – Largest distance and step in Å.

  • radiation ({"xray", "neutron", "electron"}) – Weights the atom pairs by scattering power.

  • qmax (float) – Qmax in Å⁻¹ of the termination ripples to include; 0 means none.

  • qdamp (float) – Instrumental damping and resolution broadening (as in PDFgui).

  • qbroad (float) – Instrumental damping and resolution broadening (as in PDFgui).

  • thermal (bool) – Broaden each pair by a Gaussian from the displacement parameters. False gives sharp, histogram-like peaks.

  • corrlin (float) – Linear and quadratic correlated-motion corrections (peak sharpening at small r); only with thermal=True.

  • corrquad (float) – Linear and quadratic correlated-motion corrections (peak sharpening at small r); only with thermal=True.

  • particle_diameter (float, optional) – Treat the crystal as a finite spherical particle of this diameter in Å (no periodic boundaries; the -4πρ₀r baseline is corrected for a sphere). Default: an infinite crystal with periodic boundaries.

Returns:

PDFPattern

Raises:

  • ValueError – For an unknown radiation or invalid ranges.

  • MacroError – If the calculation fails inside DISCUS.

Return type:

PDFPattern

Examples

>>> g = dc.pdf(cr, rmax=20, dr=0.01, qmax=25)
>>> g.plot()

seed(value)[source]#

Seed the random number generator, as the DISCUS command seed.

The same seed gives the same sequence of random numbers, so calculations with random elements (lots, MMC, …) repeat. value=0 seeds from the clock. With more than one OpenMP thread the order in which threads draw numbers can still vary.
