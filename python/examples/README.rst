Examples
========

Short scripts that use the ``diffuse`` package. Each one runs DISCUS when the
documentation is built, so the output and plots here are real results.

To run them (and the notebooks ``interactive_plots.ipynb`` and
``crystals_and_ase.ipynb``, crystals in Python and ASE) yourself, copy the
folder ``python/examples`` out of your DiffuseCode clone first, for example
``cp -r python/examples ~/diffuse-examples``: Jupyter saves a notebook with
its results, which would change the file in the clone and block ``git pull``.
